# The baseline cannot absorb a lasting problem

The pre-flight baseline is frozen and always shown as a second reference. The expected in-flight band comes from published effect sizes per mission day, not from the astronaut's recent data. The personal baseline updates only from days with no open event, and each update has a cap on how far it can move. A deviation that stays open past a set limit escalates to the crew medical officer. A reader may expect a fully adaptive baseline: we rejected it, because a slow pathological change would then become the new normal.
