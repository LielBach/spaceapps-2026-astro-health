# Project skills

| Skill | Use |
|---|---|
| `grill-me` | `/grill-me` — Claude interviews you round by round to stress-test a plan or design |
| `grill-with-docs` | `/grill-with-docs` — same interview, and it writes `GLOSSARY.md` and ADRs in `docs/adr/` as decisions settle |
| `grilling` | The interview logic that both commands load. Claude can also load it on its own when you say "grill" |
| `domain-modeling` | Glossary and ADR rules that `grill-with-docs` loads |
